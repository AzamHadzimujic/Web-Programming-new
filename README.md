# Web-Programming-new
Repository for the Project from the Course IT 2001 - Web Programming (2026/2027)

The Project is a Libary Management System. 
Users can login into the system to borrow available books from the library.
Librarian is responsible to track borrowed books and due dates for users (Each book needs to be returned in 7 days),
the Librarian is also responsible to keep track of which books are available and enter new books into the system.
Admin is responsible to keep the system running.
